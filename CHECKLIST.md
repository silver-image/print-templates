# Checklist before you send a print file

From the Silver Image Print & Signs guide to [how much bleed each print product needs](https://www.silverimagelondon.com/guides/how-much-bleed-does-each-print-product-need).

1. **The finished size**: the page set to the trimmed size, with the bleed added outside it.
2. **The bleed for that product**: from the [table](README.md#bleed-safe-margin-and-resolution-by-product), on every edge.
3. **Backgrounds through the bleed**: pictures and colour extended to the outer edge.
4. **Text inside the safe margin**: measured from the trim line.
5. **Fixings and bound edges**: eyelets, screws, rails, punches and spines kept clear.
6. **Resolution at the finished size**: and vector for logos and lettering.
7. **A PDF with fonts embedded or outlined.**

## Four checks a printer runs on every file

From the guide to [which file format to send to a printer](https://www.silverimagelondon.com/guides/what-file-format-for-printing).

| Check | What can go wrong | How to pass it |
|---|---|---|
| Bleed | Colour that should run off the edge stops at a white hairline | Extend artwork 3 mm past the trim on every edge |
| Resolution | Sharp on screen, soft on paper | Check with the [preflight tool](https://www.silverimagelondon.com/tools/print-preflight) at final size |
| Embedded fonts | A missing font substitutes silently and reflows the text | Embed fonts at export, or outline them |
| Page size | An A4 file for an A5 job scales, and someone has to guess how | Set the document to the finished size, plus bleed |
